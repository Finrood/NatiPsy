# Montserrat local assets

These WOFF2 subsets are Montserrat, licensed under the SIL Open Font License 1.1. The upstream source is the Google Fonts distribution of the Montserrat family:

https://fonts.google.com/specimen/Montserrat

The `latin-ext` subset is retained for Portuguese diacritics; `latin` covers the common ASCII range. The CSS uses the variable font axis for weights 400–800 and `font-display: swap`.
